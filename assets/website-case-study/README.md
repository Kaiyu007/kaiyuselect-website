# Kaiyu Select — real website captures

These are actual screenshots of the self-owned production website, captured in the dedicated Codex built-in Browser on 9 November 2026. They are not generated mockups or stock images.

`capture-records.json` records the live URL, viewport, source, production deployment and Git commit. The retained JPEGs are under `captures/`. The public derivatives are WebP files; `src/data/website-case-images.json` records their dimensions and byte sizes. Run `python3 scripts/prepare-website-case-study.py` with Pillow to reproduce them. Originals are outside `public/` and do not ship in the build.

Public captions identify that date and distinction. No customer information, signed-in dashboards or credentials appear in these captures.
